# Shopping_app

![React Native](https://img.shields.io/badge/React_Native-20232A?style=for-the-badge&logo=react)
![Expo](https://img.shields.io/badge/Expo-1B1F23?style=for-the-badge&logo=expo)

A modern **e-commerce mobile application** built with *React Native* and *Expo*, featuring product browsing, detailed product views, and a shopping cart.

---

## 📦 Features
- Browse a list of products with images and prices
- View detailed information for each product  
- Add products to a shopping cart with quantity management
- Clean, intuitive mobile interface
- Easy to extend with more features (user login, payment integration, etc.)

---

## ⚡ Installation

1. **Clone the repository:**  
```bash
git clone https://github.com/Hawra-Sa/Shopping-app.git
```
2. **Navigate to the project folder:**
```bash
cd Shopping-app
```
3. **Install dependencies:**
```bash
npm install
```
4. **Start the Expo app:**
```bash
npx expo start
```

## 📝 Usage

Browse products on the Home screen
Click a product to see its details
Add products to the Cart
The cart icon updates in real-time with the total quantity
